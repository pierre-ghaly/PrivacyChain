Step 1 — Add the Hardhat network to MetaMask

Click below. MetaMask will open with every field pre-filled — just press Approve. Uses the standard wallet_addEthereumChain RPC method (EIP-3085).

Step 2 — Import a pre-funded test account

Step 3 — Start testing

  1. Make sure MetaMask is on Hardhat Localhost (top-left network selector).
  2. Make sure the active account is the imported "Hardhat — Unsafe" one.
  3. Open the frontend: http://localhost:5173 (Vite default — adjust if your frontend uses a different port)
  4. Click "Connect Wallet" in the frontend. It will pick up the deployed contract from shared/deployments/localhost.json automatically.
Tip: If MetaMask complains about "nonce too high" after a node restart: MetaMask → Settings → Advanced → Clear activity tab data.
